## 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/WilliamMershker/ReactJsProject.git
```

Navigate to a React project folder:

```bash
cd ReactJsProject
```

Open a lesson folder containing `package.json`, then install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
